TP2 - Développement d’applications (PyQt6 & SQLite)
Système de Gestion de Carnet d'Adresses réalisé dans le cadre du cours Programmation Orientée Objet.

Description du Projet:

Ce projet consistait en la création de deux applications mettant en pratique l'utilisation d'interfaces graphiques et la gestion de bases de données vu en classe. L'objectif principal était de maîtriser l'interaction entre PyQt6 pour l'interface de l'utilisateur et SQLite.

PyQt6 est une bibliothèque logicielle permettant de concevoir des interfaces graphiques (GUI) pour des applications desktop.

SQLite est une base de données locale qui stock toutes les informations dans un fichier

Le projet se divise en deux parties:

Un carnet d'adresses connecté à une base SQLite.
Ensuite, un système de gestion de parc informatique.

Fonctionnalités Principales
 
Application A : Carnet d’adresses

Gestion de données : Connexion à une base de données locale SQLite.

Opérations CRUD Complètes : Possibilité d'ajouter, modifier, supprimer et afficher des contacts (Nom, Prénom, Téléphone, Courriel) .

Application B : Nous avons utilisé le code de la première application comme référence pour construire le code du parc informatique.

Prérequis:

-Environnement de développement configuré.

-Bibliothèque PyQt6 installée.

-Moteur de base de données SQLite (ou fichier CSV).
